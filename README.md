# Scoop bucket

Manifests for [Zeno](https://github.com/chmenegatti/zeno), a tab-less, local-first API client (REST, GraphQL, gRPC, WebSocket).

```powershell
scoop bucket add zeno https://github.com/chmenegatti/scoop-bucket
scoop install zeno
```

Installs the portable build: `Zeno` in the Start menu and `zeno-cli` on the PATH.
